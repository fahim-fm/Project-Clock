# Digital Clock ,Alarm & Stopwatch  

# live: https://fahim-fm.github.io/Project-Clock/

A web-based **Digital Clock ,Alarm & Stopwatch** built using **HTML, CSS, and JavaScript**. It displays the current time in **12-hour format**, allows users to **set alarms**, includes a **stopwatch**, and persists alarms using **localStorage**.



---

## ✨ Features

- Real-time **12-hour digital clock** with AM/PM  
- **Set multiple alarms** with **12-hour format display**  
- **Alarm sound** with **snooze and stop** options  
- **Persistent alarms** using `localStorage`  
- **Stopwatch** with start, pause, and reset functionality  
- Responsive and user-friendly design  

---

## 🛠 Technologies Used

- **HTML5** - Structure of clock, alarms, and stopwatch  
- **CSS3** - Styling, modals, and layout  
- **JavaScript (ES6)** - Clock update, alarm management, stopwatch logic, and localStorage handling  

---
## ⚙ How It Works

1. **Digital Clock**
   - Displays current time in **12-hour format** with AM/PM.
   - Updates every second in real-time.

2. **Alarms**
   - Set an alarm using the time picker.
   - Multiple alarms can be added.
   - Alarms trigger a sound and a modal when active.
   - Alarms can be **stopped** or **snoozed** (5 minutes).
   - Alarm times are saved in `localStorage` and persist after refresh.

3. **Stopwatch**
   - Start, pause, and reset stopwatch.
   - Displays **hours:minutes:seconds**.
